# Traffic Master

Traffic Master is a legacy OpenGL traffic-management prototype built with FreeGLUT and a Code::Blocks project.

The goal of the project is to simulate a 3D four-way intersection where the player manages traffic lights to prevent congestion and gridlock.

## Current Status

The project is being developed in stages.

Completed so far:
- Basic FreeGLUT window setup
- 3D perspective projection
- Elevated camera view
- Simple intersection layout
- Ground, roads, sidewalks, lane markings, and stop lines

## Tech Stack

- **Language:** C++
- **Windowing/Input:** FreeGLUT
- **Rendering:** Legacy fixed-function OpenGL
- **Project file:** `openglportable/openglportable.cbp`
- **Compiler target:** GCC / MinGW on Windows

## Project Structure

- `openglportable/main.cpp` - main application entry point and rendering code
- `openglportable/openglportable.cbp` - Code::Blocks project file
- `freeglut/` - bundled FreeGLUT headers and libraries

## Build Requirements

- Code::Blocks with GCC / MinGW
- FreeGLUT configured as provided in the repository
- Windows with OpenGL support

## Build Instructions

### In Code::Blocks

1. Open `openglportable/openglportable.cbp`
2. Build the project
3. Run the executable generated by Code::Blocks

### Command Line Example

From the `openglportable` directory:

```powershell
g++ -Wall -fexceptions -g main.cpp -I ..\freeglut\include -L ..\freeglut\lib\x64 -lfreeglut -lopengl32 -lglu32 -o bin\Debug\openglportable.exe
```

## Controls

Controls will be added as the simulation grows.

Planned controls include:
- `1` / `2` - signal group selection
- `G` / `Y` / `R` - traffic light control
- `P` - pause
- `ESC` - exit
